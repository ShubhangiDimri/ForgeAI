# Corrected evaluation copies

These are audit corrections of the original generated cases for academic,
procurement and retail. They are a separate benchmark. The historical runs and
the citation precision experiment retain the original frozen datasets. See the
root FAILURE_ANALYSIS.md for the rationale and each provenance file for the
source and corrected hashes.

All three copies passed schema and source-anchor checks. None has a measured
baseline. Before using a corrected dataset for a comparison, establish a fresh
baseline and evaluate both variants with the same pinned agent, judge and
corrected hash.
